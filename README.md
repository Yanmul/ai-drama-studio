# 短剧工作台（第一版）

个人自用的 AI 短剧工具：画布的操作方式参考 ComfyUI，节点和生成面板参考 LibTV，模型由你自己接（火山引擎、中转站，以后想接谁都行）。

## 怎么启动

1. 电脑上要有 Node.js 20 或更高版本（没有就去 <https://nodejs.org> 下载 LTS 版）。
2. 双击 `启动.command`。第一次会自动安装依赖、构建界面，要几分钟；以后再双击几秒就好。
3. 浏览器会自动打开 <http://127.0.0.1:6688>。关掉终端窗口就停止。

> 第一次双击如果提示「无法打开，因为它来自身份不明的开发者」：在访达里右键 `启动.command` → 打开 → 再点「打开」。

开发时也可以用 `npm run dev`（前端 5173 端口热更新，后端 6688）。

## 第一次打开能看到什么

自带一个示例项目《压线过弯》第 1 集：一个脚本节点、两个镜头（文本 → 视频）、一个胡柏冰的角色定妆图节点。默认用「演示模型」，不联网、不花钱，可以先把流程点一遍：

1. 点「胡柏冰（少年）定妆图」节点 → 下方弹出生成面板 → 点右下角 ↑ 生成。
2. 点「视频节点 1」→ 面板里能看到定妆图被编号成「图1」→ 在提示词里输入 `@` 可以引用它 → 生成。
3. 点脚本节点下方的「展开成镜头」，脚本按空行拆成一排「文本 → 视频」。
4. 右上角「队列」看进度和花费。

演示视频需要电脑装了 ffmpeg（`brew install ffmpeg`），没装就只给一张示意图，不影响试流程。

## 接入真实模型

右上角「模型管理」：

| 服务商类型 | 填什么 | 说明 |
|---|---|---|
| 火山引擎 | 方舟的 API key | 已预置 Seedance 2.0 / 2.0 mini、Seedream 4.0、豆包文本。**模型 ID 以方舟控制台为准**，不对就在表格里改 |
| 中转站 | 地址 + key | 已预置一个 4sapi 示例。每个模型要选「接口格式」：OpenAI 对话 / OpenAI 生图 / 火山格式 / 自定义模板 |
| 演示 | 不用填 | 试界面用 |

- 同一家中转站按 key 分组、不同分组能用的模型不同时，可以添加成多个服务商，各填各的 key。
- 中转站的视频接口各家不一样，选「自定义模板」，按它的文档填提交地址、请求体、任务号 / 状态 / 结果链接在哪个字段，不用写代码。
- 单价填了就能在面板右下角看到预估花费，队列里能看到累计花费。
- key 用 AES 加密后存在 `workspace/config/providers.json`，解密用的主密钥在 `~/.ai-drama-studio/master.key`。把项目文件夹拷给别人，别人拿不到你的 key。

## 文件都在哪

不用数据库，所有东西都在 `workspace/` 文件夹里，用访达就能看：

```
workspace/
├─ config/providers.json            服务商和模型（key 是加密的）
├─ projects/<项目>/
│  ├─ project.json                  画风、默认比例
│  ├─ characters/                   角色库
│  ├─ uploads/                      上传的素材
│  └─ episodes/ep01/
│     ├─ canvas.json                这一集的画布（自动保存，留最近 20 个历史版本 .bak1…）
│     └─ assets/<节点>/v1.mp4       每次生成的结果 + 同名 json（提示词、模型、参数）
└─ jobs/                            生成任务记录，花费统计从这里算
```

整个 `workspace/` 拷到另一台电脑就能接着用（key 要在新电脑上重新填）。

## 代码结构

```
shared/types.ts            前后端共用的类型
server/
  providers/types.ts       适配器接口（接新厂商就实现它）
  providers/volcengine.ts  火山引擎（方舟）
  providers/relay.ts       中转站（4 种接口格式 + 自定义模板）
  providers/mock.ts        演示模型
  providers/index.ts       服务商注册表、读写 providers.json
  presets.ts               参数预设：每类模型有哪些模式、参数（界面按它自动生成）
  prompt.ts                拼最终提示词：画风 + 角色外形 + @图1 换成厂商叫法
  queue.ts                 任务队列：并发上限、重试、轮询、结果下载
  storage.ts / projects.ts 本地文件读写
src/
  Canvas.tsx               画布（React Flow）
  nodes/MediaNode.tsx      五种节点
  components/GeneratePanel.tsx  选中节点后的生成面板
  components/AddNodeMenu.tsx    添加节点菜单
  components/ModelManager.tsx   模型管理
```

**接一家新厂商**：在 `server/providers/` 新建一个文件实现 `Adapter`（`test` / `submit` / `poll`），在 `providers/index.ts` 的 `ADAPTERS` 里加一行。

## 已知限制

- 参考图默认用 base64 直接塞进请求。个别模型只收公网链接时，在服务商里把「参考图传法」改成「给公网链接」，并填一个能从外网访问到本机的地址。
- 火山方舟和中转站是按官方格式和你之前项目里的写法接的，用模拟服务器核对过请求格式，**还没用真实 key 跑过**，第一次用请先生成一条短的试试。
- 还没做：镜头表视图、拼接导出成片、撤销重做、节点模板。
